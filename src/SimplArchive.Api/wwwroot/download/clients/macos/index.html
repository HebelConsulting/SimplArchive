SimplArchive desktop client — macOS

The macOS .dmg installers (Apple Silicon arm64 and Intel x64) are published as GitHub Release assets — a macOS build can't be produced by the Linux server image that hosts this page.

Download from GitHub Releases →

The .dmg is self-contained (no .NET needed) and ad-hoc signed / not notarized — Gatekeeper warns on first open (right-click → Open, or xattr -dr com.apple.quarantine the app). Windows and Linux builds are available one level up under clients/.
